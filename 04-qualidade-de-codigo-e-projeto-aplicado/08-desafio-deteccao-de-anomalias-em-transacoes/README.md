# Desafio de Projeto — Detecção de Anomalias em Transações em Python

**Módulo:** Qualidade de Código e Projeto Aplicado  
**Carga horária:** 1h · Intermediário

## Objetivo

Aplicar o conteúdo da formação (arquivos, tratamento de erros, Pandas, limpeza, automação, visualização e testes) para identificar transações suspeitas em uma base de dados.

## Estrutura

```
├── data/
│   ├── raw/          # Dados originais (não alterar)
│   └── processed/    # Dados tratados
├── notebooks/        # Análise exploratória e validação
├── src/              # Código do pipeline (carga, limpeza, detecção)
├── tests/            # Testes com pytest
└── reports/
    └── figures/      # Gráficos gerados
```

## Abordagem (a definir durante o desafio)

1. Carga e validação dos dados
2. Limpeza e engenharia de atributos
3. Detecção de anomalias (ex.: Z-score, IQR, regras de negócio)
4. Visualização dos resultados
5. Testes e documentação
