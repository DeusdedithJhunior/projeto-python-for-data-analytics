## 📌 Sobre

Repositório que unifica, em uma única trilha organizada por tema, o conteúdo de dois cursos de Python:

- **Fundamentos de Linguagem Python — Do Básico a Aplicações de IA** (Data Science Academy)
- **Formação Python for Data Analytics** (DIO)

Cada módulo indica de qual curso vem cada conteúdo.
