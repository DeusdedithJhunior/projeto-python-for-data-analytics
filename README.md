## 📌 Sobre a formação

Formação de nível **intermediário** (8h · 7 cursos + 1 desafio de projeto) voltada para a carreira de **Data Analyst**: manipulação de arquivos, tratamento de erros, preparação e transformação de dados com Pandas, automação de tarefas, visualização de dados e boas práticas de código.

## ▶️ Como executar

```bash
# Clonar o repositório
git clone https://github.com/<seu-usuario>/projeto-DIO-python-for-data-analytics.git
cd projeto-DIO-python-for-data-analytics

# Criar e ativar o ambiente virtual
python -m venv .venv
.venv\Scripts\activate        # Windows
# source .venv/bin/activate   # Linux/macOS

# Instalar dependências
pip install -r requirements.txt

# Abrir o Jupyter
jupyter lab
```
